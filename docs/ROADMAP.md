## 알려진 한계 / 주의

- **심야 뉴스 풀 얇음** — 늦은 시간엔 신선 뉴스가 적고 주제겹침 필터로 1~2건만 남을 수 있음. 낮엔 3건.
- **표지 사진 ≠ 1번 헤드라인일 때 있음** — 표지 사진은 "사진 있는 첫 뉴스"에서 가져와서, 1번 뉴스가 사진이
  없으면 다른 뉴스 사진이 표지가 됨. (thematic mismatch 가능)
- **인물(특히 정치인) 얼굴이 표지가 될 수 있음** — 원문 사진 기반이라. 필요하면 인물 클로즈업 필터 검토.
- **Gemini 오류 가능** — 엉터리 수치는 프롬프트로 상당수 거르지만 100%는 아님. 게시 후 눈으로 확인 권장.
- **팔로워 0(테스트 단계)** — 지금은 마음껏 테스트/게시 가능.
