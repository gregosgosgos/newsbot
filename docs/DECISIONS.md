# DECISIONS — 주요 결정과 이유 (+ 하지 말 것)

새 채팅이 "왜 이렇게 되어 있는지" 몰라서 되돌리는 실수를 막기 위한 문서.

## 인프라

- **배포 = GitHub Actions (Railway 아님)**. 이유: Railway는 상시 서버라 월 비용 발생. Actions는
  cron 실행이라 완전 무료. (`server.py`·`Procfile`은 구 Railway 흔적, 미사용.)
- **레포 public**. 이유: 인스타가 이미지를 `raw.githubusercontent.com` 공개 URL로 가져가야 함.
- **AI 리라이팅 = Gemini 무료 티어** (Claude API 아님). 이유: 25계정 분량을 무료로. 설계·디버깅은 Claude 담당.
- **인스타 게시 = Instagram API with Instagram Login** (graph.instagram.com). 페이스북 페이지 연동 불필요.

## 콘텐츠 & 저작권

- **원문 그대로 안 베낌** — AI가 팩트만 뽑아 새 문장. 캡션에 원문 링크(트래픽 유도). `is_factual_risk`면 스킵.
- **화제성 = 보도량**. 여러 매체가 동시에 다루는 뉴스일수록 클러스터가 큼 → 그 크기로 화제성 근사.
- **자료사진 = 원문 og:image**. 사용자가 저작권 트레이드오프를 승인함(원문 링크 attribution 조건).
  단 **로고/저품질은 필터**(`_is_photographic`)하고, raw 사진은 커밋 안 함(렌더된 카드만 공개).

## 중복 제거 (3중) — 되돌리지 말 것

1. 같은 사건 제목만 다른 것 → `_similar` (수집 클러스터링).
2. 당일 주제 겹침(본문 핵심어) → `topic_overlaps` 느슨(jac≥0.18 or 3자+ 2개). 한국어 표면 토큰은 신호가 약해
   이 임계값이 실측으로 맞음(구별돼야 하는 쌍은 공유 강한토큰 0개, 겹치는 쌍은 2~3개).
3. 어제와 판박이 → `topic_overlaps` 엄격(jac≥0.34 or 4개) + `recent_token_sets`. **진전 있는 후속 기사는
   통과**시키려고 엄격하게. cross-day는 **오늘(0일차) 제외** — 안 그러면 하루에 여러 번 실행 시 과필터됨.

## 디자인 (되돌리면 사용자가 지적했던 것들)

- **카드는 코드 렌더**(AI 이미지 X). 이유: "매일/몇 년 뒤에도 동일 재현". → Canva/Figma로 갈아타지 말 것.
- **줄바꿈은 `_wrap_smart`**: 구두점 경계에서 끊되 "습니다." 같은 외톨이 줄 방지. (사용자가 강하게 요구)
- **수치 박스·팩트 번호는 textbbox로 실측 정렬**(하드코딩 offset이면 아래로 쏠림/어긋남 — 사용자 지적).
- **수치 라벨은 숫자 아래**(옆에 붙이면 긴 수치일 때 잘림).
- **말투는 "~다.~다." 금지**, 연결어미·쉼표로. (rewriter 프롬프트)
- **섹션 라벨 "쉽게 풀어보면"** (원래 "쉽게 말하면" — 내용이 짧지 않고 긴 풀이라서 라벨을 맞춤).
- **facts는 완결 문장, 서술어 자르지 말 것**("부담 커" X → "배송비 부담 가중" O), 어미 다양하게.
- **표지는 사용자가 만족("아주 좋다")** — 함부로 갈아엎지 말 것.

## 마케팅 (카드뉴스 계정 벤치마킹 반영)

- **캡션 = 뉴닉 구조**: 공감 오프닝 → 뉴스 리스트 → 참여 질문 → 저장·팔로우 CTA → 원문 → 타깃 해시태그 10개.
  계정별 페르소나는 `instagram_poster._CAPTION`.
- **저장 유도**: 마지막 카드에 북마크 CTA. 우리 카드는 정보 요약이라 "저장"과 궁합이 좋음.

## 운영 함정 (안티패턴)

- 샌드박스에서 `git` 돌리지 말 것 → Windows auto_sync와 `.git` 충돌(index.lock). [OPERATIONS](OPERATIONS.md)
- `.bat` 더블클릭 안 됨(보안 SW) → 터미널/Run 대화상자.
- 하루에 워크플로우 여러 번 돌리면 뉴스 풀이 겹쳐 게시물이 얇아질 수 있음(정상 — 낮엔 3건).
